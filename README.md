# بایگانی خصوصی

فقط مریم و Claude به این مخزن دسترسی دارند.

- `vault_src/` متنِ بازِ همهٔ بخش‌های خصوصی: سیمرغ، لایهٔ ایران، ساخت ایران، دفتر پروژه، فهرست وضعیت. نسخهٔ رمزگذاری‌شده‌اش در مخزن عمومی است (`daneshsara/vault/bundle.enc`).
- `mk/` سازنده‌های ویکی سیمرغ و اسکریپت‌های قفل کردن صندوق و نسخهٔ اشتراکی (`rebuild.sh`، `share.sh`).
- `share-site/` صفحهٔ قفلِ نسخهٔ اشتراکی سیمرغ.
- `project-docs/` متن اسنادی که در پروژهٔ claude.ai بود.
- شاخهٔ `github-io-before-message-cleanup` تاریخچهٔ کامل سایت پیش از پاک کردن پیام‌های کامیت.
- شاخهٔ `par-simorgh-old-site` سایت قدیمی پَرِ سیمرغ.

رمزها هیچ‌جا ذخیره نمی‌شوند. کتاب‌ها و PDFها هم اینجا نیستند.
